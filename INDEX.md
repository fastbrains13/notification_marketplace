## 📋 По ролям

### Для новичка 🌱

**День 1: Старт**
1. Прочитать [QUICKSTART.md](QUICKSTART.md) (5 мин)
2. Запустить `php init.php`
3. Отредактировать `.env`
4. Открыть админку: `http://localhost/admin/`
5. Добавить магазин и ключи
6. Запустить `php check_orders.php`

**День 2: Углубление**
1. Прочитать [ADMIN_SETUP.md](ADMIN_SETUP.md) (15 мин)
2. Попробовать API через cURL (из [EXAMPLES.md](EXAMPLES.md))
3. Поэкспериментировать с админкой

### Для администратора 👔

**Неделя 1: Развертывание**
1. Прочитать [QUICKSTART.md](QUICKSTART.md)
2. Прочитать [ADMIN_SETUP.md](ADMIN_SETUP.md)
3. Развернуть локально
4. Протестировать с маркетплейсами
5. Добавить магазины

**Неделя 2: Production**
1. Прочитать [SECURITY.md](SECURITY.md)
2. Выполнить security checklist
3. Настроить Nginx
4. Настроить SSL
5. Настроить Cron задачу
6. Настроить мониторинг

### Для разработчика 👨‍💻

**День 1: Обзор**
1. Прочитать [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md)
2. Изучить [EXAMPLES.md](EXAMPLES.md)
3. Запустить `php check_orders.php`

**День 2-3: Интеграция**
1. Написать скрипт использующий API
2. Автоматизировать добавление магазинов
3. Интегрировать с другими системами

**День 4+: Усовершенствование**
1. Добавить новые маркетплейсы
2. Оптимизировать код
3. Улучшить обработку ошибок

### Для DevOps 🛡️

**Неделя 1: Setup**
1. Прочитать [SECURITY.md](SECURITY.md) полностью
2. Настроить Nginx
3. Настроить SSL/TLS
4. Настроить HTTP Auth или API tokens

**Неделя 2: Hardening**
1. Выполнить security checklist (из [SECURITY.md](SECURITY.md#🔟-развертывание-без-проблем))
2. Настроить firewall
3. Настроить rate limiting
4. Настроить логирование и мониторинг

**Неделя 3: Operations**
1. Настроить backup скрипт
2. Настроить мониторинг (alerting)
3. Создать runbook для incident response
4. Документировать процессы

### Быстрая проверка

1. **Используйте поиск:** `Ctrl+F` в браузере
2. **Проверьте эти файлы:**
   - [QUICKSTART.md](QUICKSTART.md) - 9 из 10 проблем решаются здесь
   - [EXAMPLES.md](EXAMPLES.md) - Примеры для вашего случая
   - [MIGRATION_SUMMARY.md](MIGRATION_SUMMARY.md) - Для старого format

3. **Проверьте логи:**
   ```bash
   tail -f storage/debug.log
   ```

4. **Проверьте конфиг:**
   ```bash
   php -r "require 'config.php'; print_r(\$config);"
   ```

### Если все еще не понятно

Вернитесь к основам:
1. [QUICKSTART.md](QUICKSTART.md) - Начните заново шаг за шагом
2. Убедитесь что `php init.php` выполнен
3. Убедитесь что `.env` заполнен правильно
4. Запустите `php check_orders.php`
