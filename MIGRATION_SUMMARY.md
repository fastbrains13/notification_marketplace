# Итог миграции: CONFIG.PHP → ENV + ADMIN

## 📊 Что изменилось?

### Было (старый формат)

```php
// config.php
$config = [
    'bot_token' => 'xxx',  // жёсткое значение
    'telegram_chat_id' => 'yyy',  // жёсткое значение
    'stores' => [
        'AquaCam' => [
            'ozon' => [
                'client_id' => '123',  // жёсткое значение
                'api_key' => 'secret'  // жёсткое значение
            ],
            // ... остальное ...
        ]
    ]
];
```

❌ Проблемы:
- Ключи в коде (небезопасно для production)
- Нужно редактировать PHP для добавления магазина
- Все в одном файле
- Не удобно работать с несколькими магазинами
- Сложно использовать для teamwork (конфликты в git)

---

### Стало (новый формат)

#### 1️⃣ Telegram конфиг в `.env`:

```env
# .env
TELEGRAM_BOT_TOKEN=xxx
TELEGRAM_CHAT_ID=yyy
```

#### 2️⃣ Магазины в JSON БД:

```json
// storage/stores.json
{
  "AquaCam": {
    "ozon": {
      "client_id": "123",
      "api_key": "secret"
    },
    "wildberries": { ... },
    "yandex": { ... }
  },
  "MyShop": { ... }
}
```

#### 3️⃣ Управление через Админку:

```
http://localhost/admin/
```

✅ Преимущества:
- Ключи не в коде (безопасно)
- Управление магазинами через веб-интерфейс
- REST API для программного управления
- Просто добавлять/удалять магазины
- Отделение конфигурации от кода
- Удобно для teamwork (нет конфликтов в git)

---

## 📈 Сравнение

| Критерий | Было | Стало |
|----------|------|-------|
| **Где конфиг?** | config.php | .env + storage/stores.json |
| **Как добавить магазин?** | Редактировать PHP код | Админка / API |
| **Безопасность** | Ключи в git | Ключи локально (в .gitignore) |
| **Удобство** | Низкое | Высокое |
| **Масштабируемость** | Плохая | Хорошая |
| **Автоматизация** | Сложно | REST API |
| **Backup** | Вручную | JSON файл |

## 🆕 Новые возможности

Красивый веб-интерфейс для управления магазинами:

### 🌐 REST API

Программное управление магазинами:

```bash
GET    /api/stores.php           # Получить все
POST   /api/stores.php           # Добавить
PUT    /api/stores.php           # Обновить
DELETE /api/stores.php           # Удалить
```

Примеры в `EXAMPLES.md`

### Вариант 3: Через API

```bash
# Добавить магазин
curl -X POST http://localhost/api/stores.php \
  -d '{"name":"AquaCam"}'

curl -X PUT http://localhost/api/stores.php \
  -d '{
    "storeName":"AquaCam",
    "marketplace":"ozon",
    "client_id":"123",
    "api_key":"secret"
  }'

# Проверить
php check_orders.php
```

## 🐛 Если что-то не работает

### Быстрая диагностика

```bash
# 1. Проверить конфиг
php -r "require 'config.php'; print_r(\$config);"

# 2. Проверить БД
ls -la storage/
cat storage/stores.json

# 3. Проверить логи
tail -f storage/debug.log

# 4. Проверить .env
grep -v '^#' .env | grep -v '^$'
```

### Частые ошибки

| Ошибка | Решение |
|--------|---------|
| "stores.json not found" | Запустить `php init.php` |
| "Empty store name" | Проверить .env - заполнены ли TELEGRAM_* |
| "API key required" | Когда сохраняете ключи - оставьте пусто, если нет значения |
| "Permissions denied" | `chmod 755 storage/` |
